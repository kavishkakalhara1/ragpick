# Internal escalation guide (support staff only)

Escalate a ticket to Tier 2 when a customer reports error E-3301 twice within 30
days, or when a replacement unit shows the same fault.

For warranty replacements, support agents may approve an advance replacement
without waiting for the defective unit to be returned. Use the RMA code prefix
ADV- in the ticketing system.

Goodwill credits of up to $25 can be issued without manager approval.
