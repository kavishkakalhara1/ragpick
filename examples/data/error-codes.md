# Error codes

The thermostat displays an error code when it detects a problem.

- **E-1042**: Low battery. Replace the two AAA batteries or connect a C-wire.
- **E-2210**: No power to the heating system. Check the breaker and the furnace
  door switch.
- **E-3301**: Temperature sensor fault. Contact support; the unit may need to be
  replaced under warranty.
- **E-4017**: Firmware update failed. Keep the thermostat on Wi-Fi; it retries the
  update automatically every 6 hours.
- **E-5120**: Wiring mismatch between the Y1 and G terminals. Re-check your wiring
  labels against the installation guide.

If an error code is not listed here, restart the thermostat and contact support
with the code and your device serial number.
